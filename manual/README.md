# The Omarchy psX Manual

A guide to the Omarchy desktop on PlayStation: preparing the Linux system, using the desktop, understanding hardware limits, and keeping a recovery path.

**Start here:** this is a development project, with hardware observations from one PS4 Slim with a Baikal B1 southbridge. The repository supplies source and build tools; it does not supply a complete, newly qualified Linux psX installation image. Start with [Getting Started](02-getting-started.md) before choosing any downloads.

The manual begins with a console that already has a working Linux boot environment. Console access and security modification are outside its scope.
